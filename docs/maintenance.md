## 2026-10-12：HTTP 新建对话兼容修复

新建对话的临时标识改用 `crypto.getRandomValues()` 生成 128 位随机数。局域网 HTTP 浏览器不提供 `crypto.randomUUID()`，旧代码在发送创建请求前就报错；已有会话不经过此调用。

开发目录中已在实际 HTTP 浏览器复现旧报错，并确认修复后的临时会话标识互不相同、首条消息回显保留、激活后仍为同一个 store 并执行 attach。类型检查、构建及既有 session-registry 的 5 项测试通过。发布副本同步相同源码，复用这些结果；没有新增测试文件或依赖，没有调用模型。本次仅同步这一独立兼容修复。
