## 2026-10-12：手机通过局域网访问与手机布局

新增可选的局域网访问：启动时加 `--lan` 才监听 `0.0.0.0`，手机和电脑连同一个 Wi-Fi 后打开打印出来的地址，输入本次启动的 6 位访问码即可；本机访问永远不需要码。同时补上窄屏布局与一批只有真机才会暴露的修复。

| 项 | 内容 |
| --- | --- |
| 来源校验 | 新的 `server/request-guard.ts` 校验 `Host` 与 `Origin`：始终接受回环名，`--lan` 时加上本机网卡地址，另可用 `OMP_WEB_ALLOWED_HOSTS` 追加（留给反向代理）。所有请求都过这一层，拒绝返回 403。这同时挡掉了跨站页面直连本机 WebSocket 与 DNS 重绑定 |
| 配对 | 新的 `server/lan-auth.ts`：每次启动一个 6 位码；同一地址错 5 次锁 10 分钟，累计错 20 次自动换码；设备令牌 32 字节随机数只存 SHA-256 摘要，Cookie 为 `HttpOnly; SameSite=Strict; Max-Age=30 天`，落盘 `<dataDir>/lan-devices.json`，30 天未用即丢弃；`/api/lan*` 只对本机开放（非回环一律 403） |
| 前端 | 启动先问 `GET /api/pair`，未配对只渲染配对页（不连 WebSocket、不拉索引），`#pair=<码>` 扫码直登并清掉地址栏里的码；设置页新增「手机访问」（只在本机显示：地址、访问码、二维码、换码、全部退出）；复制改走 `web/src/lib/clipboard.ts`，HTTP 页面退回 `execCommand` |
| 手机布局 | 760px 以下：侧栏变抽屉（遮罩、导航、Esc 都能关，开合不写桌面偏好）、右侧面板与设置铺满、隐藏拖动条；`(hover: none)` 下悬停按钮常显，`(pointer: coarse)` 下按钮 36px、会话行 40px、字段不小于 16px；触屏回车只换行；`100dvh` + iOS 的 `visualViewport` → `--app-h`，安全区用 `env()` 让开；主屏幕清单与图标（`web/public/`）随包发布 |
| 依赖 | 新增 `qrcode-generator@2.0.4`（无传递依赖），只用于把配对链接画成二维码 |
| 接口版本 | 升为 6，需要重启网关并刷新页面 |

真机反馈后续修的四处（都在本副本中）：

| 修复 | 内容 |
| --- | --- |
| HTTP 下新建对话 | 临时会话标识改用 `crypto.getRandomValues()`：局域网 HTTP 页面不提供 `crypto.randomUUID()`，旧代码在发送创建请求前就报错 |
| 手机上输入框提示 | 触屏下忽略宿主传的提示文字，一律显示「输入消息」，不再出现 Alt+Enter 这类手机上不存在的快捷键 |
| 回复底部被挡 | 760px 以下恢复对话底部留白并关闭输入区上方的渐隐层；顺带把改动卡片的路径行盒固定（`line-height` + `text-size-adjust: 100%`），避免手机按块放大字体后与同行统计数字错位 |
| 展开的处理过程 | 展开时表头钉在滚动区顶部，长列表可以就地收起；滚动范围限于这一折，滚过即松手，不遮挡下面的回答 |
