# 会话显示与侧栏

## 历史与上下文压缩

上下文压缩只改变模型接收的内容。对话页面保留压缩前的文字，并在压缩位置显示“上下文已压缩”。刷新、重新打开会话后，历史仍然可见。

页面沿当前会话分支显示历史；编辑重发和分叉产生的废弃分支不会混入正文。`/clear` 仍清空当前显示，已清空的内容不会因这项功能重新出现。

## 查看 CLI 子代理

| 情况 | 操作 |
| --- | --- |
| CLI 会话已经结束 | 从侧栏打开会话，右侧“子代理”页会恢复已保存的任务和过程 |
| 已识别到外部 `omp --resume` / RPC 会话占用 | 打开后自动只读查看，历史和子代理落盘记录每 1.5 秒同步 |
| CLI 新建会话，命令行没有会话文件路径 | 会话“更多”菜单 → “只读查看（CLI 会话）” |
| 需要继续在 Web 中发送消息 | 退出占用该会话的 CLI，再点“重新连接” |

只读查看不会启动另一个会话写入进程。发送、编辑重发、重跑、子代理追加指令和停止均停用。CLI 的文字在写入会话文件后同步；尚未落盘的逐字增量不在此范围内。

恢复依据是当前分支的 `task` 调用、结果和对应子代理会话文件。CLI 没有保存的过程无法恢复。无法从记录确认完成的任务显示“未结束”，避免把它当作已完成。

## 流式 Markdown

输出过程中即可显示标题、加粗、列表、表格、代码块和公式。解析按 120 毫秒节流，已完成段落复用结果；代码高亮在输出结束后补齐。内容始终经过 HTML 消毒。

## 调整侧栏

拖动左侧栏右边缘、右侧栏左边缘即可调整宽度。宽度保存在当前浏览器，刷新后恢复。双击边缘恢复默认宽度；聚焦边缘后，也可用左右方向键调整，Home 恢复默认。

正文与输入框始终以中间对话区域的中心线对齐。默认左侧 268px、右侧 400px；窄屏保留右侧栏覆盖显示方式。

## 更新后启用

本次网关接口版本为 5。执行 `ompweb --restart` 重启服务并刷新页面，或按 README 的手动启动方式重新启动。
